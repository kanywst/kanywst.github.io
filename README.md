# kanywst.github.io

kanywst's profile page — identity, authorization & cloud native security. A data-driven React + Vite
site (selected work, upstream pull requests, issues, security advisories, 0-draft) rendered from
`src/data/profile.json` and auto-synced daily from the GitHub API.

Live: <https://kanywst.github.io/>

## Develop

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
```
